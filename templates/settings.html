Cara mendapatkan informasi koneksi
  • Tanyakan ke tim IT Mualimat: URL server SLIMS dan API key yang aktif.
  • URL biasanya berbentuk: http://perpus.mualimat.sch.id
  • API key dapat dibuat di panel admin SLIMS: System → REST API
  • Endpoint default SLIMS Akasia/Bulian: /api/v1/loan
